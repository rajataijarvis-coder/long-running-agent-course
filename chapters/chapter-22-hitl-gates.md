# Chapter 22: HITL Gates

## What We'll Cover
- Human-in-the-loop gates
- Which actions need approval
- Timeout + default behavior
- Signaling the workflow

## Irreversible Actions
Deploying to production, deleting data, spending beyond budget, merging to main.

## Exercise
Add a HITL gate before any git push to origin/main.

## Key Takeaway
Autonomy does not mean no human oversight. Gate irreversible actions.
