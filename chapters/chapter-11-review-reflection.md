# Chapter 11: Reviewer and Reflection Agents

## What We'll Cover
- Independent review with fresh context
- Reflection on failure
- Feeding failure traces back into the next attempt
- Building a reviewer that says no

## Reviewer: Fresh Eyes
The reviewer examines the Lead's work without seeing its reasoning.

## Reflection: Learn from Failure
When verification fails, reflection identifies root cause and suggests a new approach.

## Exercise
Build a reflection agent that proposes 3 hypotheses for a test failure.

## Key Takeaway
A system that cannot say no will ship broken code. A system that cannot reflect will repeat mistakes.
