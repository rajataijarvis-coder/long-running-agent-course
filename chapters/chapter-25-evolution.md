# Chapter 25: Offline Evolution

## What We'll Cover
- Self-improvement without live risk
- Prompt evolution pipeline
- Eval harness for prompts
- Promotion criteria

## Propose → Evaluate → Promote
Propose a new prompt, evaluate against baseline on held-out cases, promote only if it wins.

## Exercise
Take one prompt and generate 2 variants. Test them on failure traces.

## Key Takeaway
Prompt evolution must be gated by real evals.
