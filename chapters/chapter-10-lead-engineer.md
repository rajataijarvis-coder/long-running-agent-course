# Chapter 10: The Lead Engineer

## What We'll Cover
- Why one agent must own all writes
- The Lead Engineer loop
- Avoiding design drift
- When to use Claude SDK as the Lead

## The Single Writer Principle
One Lead Engineer owns all coupled writes to keep design coherent.

## Lead Engineer Loop
Plan → apply → verify → checkpoint → reflect if needed.

## Exercise
Implement a Lead Engineer that writes code, runs tests, and reflects on failure.

## Key Takeaway
Design coherence requires a single writer. Reviews happen after.
