# Chapter 17: Tiered Memory

## What We'll Cover
- Three types of memory: episodic, semantic, procedural
- How the LRA maps them to files/tables
- When to use each type
- Retrieval strategies

## Three Memory Types
| Type | What | Storage |
|------|------|---------|
| Episodic | What happened | events.ndjson |
| Semantic | Facts | semantic_memory table |
| Procedural | How to do things | skill library |

## Exercise
Design a schema for semantic_memory.

## Key Takeaway
Different memories need different retrieval strategies.
